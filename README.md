# Coisas web no geral

Exercícios de HTML, CSS e JavaScript das aulas da faculdade e dos cursos da Alura, mais alguns projetos pequenos.

## Conteúdo

| Pasta | O que tem |
|---|---|
| `html/` | Exercícios de HTML: tipos de input, tabelas, ícones, marca d'água, página de login |
| `ProjetosWeb/` | Os mesmos exercícios organizados com CSS, ícones e imagens separados |
| `lembre aqui/` | Projeto "Lembre Aqui": telas de login, cadastro e home com CSS e JavaScript próprios |
| `Alura.js/` | Exercícios de JavaScript (arrays, callbacks, `forEach`) |

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como executar

Clone o repositório e abra qualquer arquivo `.html` no navegador.

```bash
git clone https://github.com/peluca2007/Coisas-web-no-geral.git
```
